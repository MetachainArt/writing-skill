# 구름다리 휴게소 — 서비스 기획서 v0.1

> 먼저 떠난 아이들이 잠깐 쉬어 가는 구름 위의 휴게소.
> 보호자는 아이의 별을 밝히고, 꽃과 간식을 놓고, 편지를 부치고, 아이 곁을 잠깐 걷다 간다.

- 주소(예정): **https://bridge.metacint.com**
- 형태: 웹 기반 3D 메타버스(설치 없음, 모바일·PC 브라우저)
- 상태: MVP 구현 완료(이 저장소 `cloudbridge/`), 데이터는 아직 기기 로컬 저장

---

## 0. 레퍼런스(kkoristar.com) 분석에 대해 — 솔직한 한계

요청받은 kkoristar.com 은 이 작업 환경의 네트워크 정책에서 차단되어 **직접 열어 보지 못했다**(프록시 403).
웹 검색에서도 해당 서비스에 대한 제3자 기술·보도는 찾지 못했다. 따라서 아래 "레퍼런스 분석"은
kkoristar 자체가 아니라 **같은 카테고리(국내외 온라인 펫 추모 서비스)의 공통 패턴**을 분석한 것이다.
kkoristar 고유의 기능·가격·톤은 확인되지 않았으므로 추측하지 않았다. 사이트 화면을 캡처해 주면 그 부분만 바로 보강할 수 있다.

### 0.1 카테고리 공통 요소 (확인된 서비스 기준)

| 서비스 | 확인된 요소 | 출처 유형 |
|---|---|---|
| 페티앙(국내) | 회원가입 없이 무료 모바일 추모장, 카카오톡/문자 전송 | 서비스 공식 페이지 |
| 펫콤(국내) | 장례식장 운영사의 온라인 추모관 게시판 | 서비스 공식 페이지 |
| 포포즈 '걸어온'(국내) | 반려동물 가상 전시관 생성, 추억 공유로 위로 받기, 펫로스 케어로 확장 | 업계 언론(데일리벳) |
| rainbowsbridge.com(해외) | 가족 초대, 장난감·간식 놓기, 주간 촛불 의식 | 서비스 공식 페이지 |
| iHeartDogs Rainbow Bridge(해외) | 가상 꽃, 다른 추모관에 위로 메시지 | 서비스 고객센터 |
| SoulBridge(해외 앱) | 편지, 앨범, 가상 간식·장난감·선물 | 서비스 공식 페이지 |
| Memorygram(해외) | QR 메달 → 가상 추모관, 아이 소리·노래 재생, 가족 헌사 | 서비스 블로그 |
| EverPaw(해외) | 기본 기능 영구 무료 | 서비스 소개 글 |

**공통 패턴**: ① 사진+날짜+추모글 카드 ② 가상 헌화/촛불/간식 ③ 방명록·편지 ④ 공유(카톡/링크/QR) ⑤ 무료 기본 + 유료 확장.
**카테고리의 빈틈**: 거의 전부가 "페이지"다. 걸어 다닐 수 있는 **공간**, 아이가 **움직이는 존재**로 있는 경험, 다른 보호자와 **같은 장소에 있다는 감각**은 사실상 없다(검색 범위 내). NYU ITP 2024 논문 프로젝트와 "Rainbow Bridge – Pet Tribute AI World" 정도가 공간/세계 개념을 건드리지만 2D 캔버스이거나 실험작이다. → **구름다리 휴게소의 자리는 여기다.**

### 0.2 왜 지금인가 (근거)

- 농림축산식품부 「2025년 반려동물 양육현황 조사」(2026.02 발표, 국가승인통계): 반려동물 양육 가구 비율 **29.2%**.
- KB금융경영연구소 「2025 한국 반려동물 보고서」: 사별 경험 가구 중 **54.7%** 가 펫로스 경험, 그중 **83.2%** 가 심각한 상실감·우울감. 가장 흔한 증상은 "돌봄 부족에 대한 자책·후회"(71.5%, 복수응답). 충격은 **20·30대, 1인 가구**에서 더 큼.
- 수치 해석 주의: 농식품부와 KB 는 표본·산정 방식이 달라 가구 수를 직접 비교하면 안 된다. 펫로스 수치는 민간 보고서다.

## 1. 제품 정의

| 항목 | 내용 |
|---|---|
| 한 줄 | 먼저 떠난 반려동물을 위한, 알록달록한 구름 위의 추모 메타버스 |
| 핵심 약속 | "아이는 여기서 아프지 않고, 기다리지 않고, 잘 쉬고 있어요" |
| 핵심 행동 | 별 만들기 → 아이 곁에 가기 → 무언가 놓고 가기 → 다시 오기 |
| 톤 | 슬픔을 부정하지 않되 어둡지 않게. 파스텔·낮은 채도의 레인보우. 존댓말, 짧은 문장 |
| 안 하는 것 | 애도 중 결제 유도, 아이 목소리/인격 흉내 내는 AI, 추모 데이터 인질(언제든 내보내기) |

### 1.1 타깃

| 페르소나 | 상황 | 원하는 것 | 우리의 답 |
|---|---|---|---|
| **1인 가구 20·30대 보호자** | 아이를 보낸 직후, 주변에 말할 사람이 적음 | 유난이 아니라는 확인, 매일 들를 곳 | 별·펫 아바타·편지·힐링 라운지 |
| **가족 단위 보호자** | 가족 각자 애도 방식이 다름 | 함께 기억하는 장소, 아이들(자녀)도 쓸 수 있는 형태 | 공유 링크·가족 공동 관리(V1)·그림 같은 월드 |
| **장례식장·동물병원** | 장례 이후 케어가 비어 있음 | 보호자에게 건넬 "다음" | B2B 화이트라벨·QR 메달(V2) |

### 1.2 경험 원칙 (버전업의 기준)

1. **공간이 먼저**: 메뉴가 아니라 장소로 기억되게. 모든 기능은 월드 안의 사물(우체통, 나무, 문)에 붙인다.
2. **아이가 살아 움직인다**: 별 옆에서 아이 아바타가 거닐고, 보호자가 다가가면 반긴다. 과장하지 않는다(말하지 않는다).
3. **혼자가 아니다**: 다른 아이들의 별이 보이고, 남이 놓은 꽃이 보인다. V1에서 실시간 방문자까지.
4. **의식(ritual)이 있다**: 별 생성 세리머니, 보름밤 합동 등불, 기일 알림. 애도는 반복되는 의식에서 가벼워진다.
5. **취약한 순간에 팔지 않는다**: 생성 흐름·추모 카드에 결제 버튼 없음. 유료는 "더 꾸미고 싶을 때" 설정에서만.

                    │
          무지개 구름다리 🌈 (7색 산책로, 난간 등)
                    │
 ┌──────────────────┴─────────────────────────┐

| 내 섬 꾸미기 | 별 주변 조형물(집, 캣타워, 방석) 배치 | 편집 | 🔜 V2 |

### 2.1 펫 아바타
- 종: 강아지, 고양이, 토끼, 새, 햄스터·설치류, 그 밖의 아이. 색은 별 빛깔과 동일.
- 전부 원시 도형(구·캡슐·원뿔)으로 만든 로우폴리 → 외부 에셋·로딩 없음, 어떤 기기에서도 가볍다.
- 행동: 자기 별 주변 1.4~4m 거닐기 → 보호자가 6m 안에 오면 다가와서 1.4m 앞에 멈춤 → 2.2m 안이면 "반가움"(꼬리·고개·점프).
- 머리 위 작은 후광: "떠난 아이"라는 표식. 말풍선·음성 없음(원칙 2).

### 2.2 별(추모 유닛)
- 받침 + 색 링 + 떠 있는 빛 구슬 + 이름표. 헌화 수에 따라 꽃(최대 10), 촛불(최대 6), 간식(최대 5)이 실제로 받침 주변에 쌓인다. 쓰다듬기 수에 따라 빛이 커진다.
- 배치: 정원 중심의 황금각 나선 → 몇 백 개까지 겹침 없이 확장. 1,000개 이상이면 "정원 2구역"(섬 추가) 로 확장(V1).

## 3. 기능 목록

### 3.1 MVP (구현 완료)
- 입장 화면(방문자 이름), 입장 전 섬을 도는 시네마틱 카메라
- 3인칭 이동(WASD/방향키/조이스틱), 드래그 시점, 휠 줌, 섬·다리·정거장 지형 충돌
- 별 만들기: 이름·호칭·종·품종·생일·건넌 날·별 빛깔·사진(256px 로 자동 축소)·한마디
- 세리머니(구름다리 건너기) → 추모 카드 자동 오픈
- 추모 카드: 함께한 일수/건넌 지 일수 자동 계산, 4종 헌화, 편지 목록, 공유, 아이 곁으로 이동, 별 내리기
- 하늘 우체통(대상 선택), 기억의 나무(익명 위로), 힐링 라운지, 도움말, 다리/문 안내
- 별 목록(최근순, 헌화·편지 수) → 순간이동
- 낮/노을/밤, 반딧불, 별하늘, 꽃잎, 등불, 생성음(WebAudio, 외부 파일 없음)
- 공유 링크: 별 데이터를 URL 해시에 담아 **백엔드 없이** 가족에게 전달(열면 상대 기기에 별이 생김)
- 샘플 별 6개(삭제 불가 표시) — 빈 정원으로 시작하지 않게

## 4. 기술 아키텍처

### 4.1 현재 (MVP)
- **Vite + three.js(0.187)**, 프레임워크 없음. 빌드 결과 ≈ 160KB gzip. 외부 폰트·에셋·CDN 0개 → 어디서든 즉시 로드.
- 렌더링: 조명 3개(반구+태양+환경), 그림자 없음(가짜 그림자 원판), 꽃·꽃잎은 InstancedMesh → 저사양 폰에서도 동작.
- 저장: `localStorage` (`cloudbridge.v1`), 공유는 URL 해시 base64url.
- 배포: GitHub Pages 워크플로 포함, `public/CNAME` = bridge.metacint.com.

### 4.2 V1 목표 구조
```
브라우저(three.js SPA, 정적 호스팅)
   │  REST/Realtime (supabase-js)
   ▼
Supabase: Auth(카카오/구글) · Postgres(별/편지/헌화/가족) · Storage(사진/음성) · Realtime(presence, 등불 이벤트)
   │
   ├─ Edge Function: 알림(이메일/알림톡), 욕설·위기 문구 필터, 이미지 리사이즈
   └─ cron: 기일 알림, 보름 이벤트 스케줄
```
- `src/store.js` 가 유일한 저장 경계. 함수 시그니처(add/get/offer/addLetter…)를 유지한 채 구현만 Supabase 로 교체.
- Presence 는 위치(x,z,yaw)를 초당 5회 브로드캐스트, 같은 섬 50명 상한 → 넘으면 섬 인스턴스 분할("정원 2구역").

## 5. 수익 모델 (원칙: 애도 중엔 팔지 않는다)

| 구분 | 내용 | 가격 가설 |
|---|---|---|
| 무료 | 별 1개 이상 무제한, 헌화·편지·공유·사진 20장, 영구 보관 | 0 |
| 별 업그레이드(1회) | 사진 무제한·영상·조형물·배경음·별자리 | 19,000~29,000원 |

| B2B | 장례식장·병원 화이트라벨 섬, 입장권 번들, QR 메달 | 월 구독 + 메달 단가 |

- 무료 사용자의 데이터를 유료 전환 지렛대로 쓰지 않는다(내보내기 항상 가능).
