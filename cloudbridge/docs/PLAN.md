# 구름다리 휴게소 — 서비스 기획서 v0.1

> 먼저 떠난 아이들이 잠깐 쉬어 가는 구름 위의 휴게소.
> 보호자는 아이의 별을 밝히고, 꽃과 간식을 놓고, 편지를 부치고, 아이 곁을 잠깐 걷다 간다.

- 주소(예정): **https://bridge.metacint.com**
- 형태: 웹 기반 3D 메타버스(설치 없음, 모바일·PC 브라우저)
- 상태: MVP 구현 완료(이 저장소 `cloudbridge/`), 데이터는 아직 기기 로컬 저장

## 0. 레퍼런스 분석 — 꼬리별(kkoristar.com)

### 0.0 확인 방법
이 작업 환경에서는 kkoristar.com 접속이 차단되어, 리도가 보내준 **실사용 화면 캡처 14장**(2026-10, iPhone Safari·Android Chrome, Threads 공유 영상 포함)을 기준으로 분석했다. 캡처에 없는 기능(결제, 계정 구조 상세)은 추정하지 않았다.

### 0.1 꼬리별에서 확인된 것

| 영역 | 확인된 내용 |
|---|---|
| 공간 | ① 어두운 목재 실내 **추모관**: 사물함 벽(사진 액자+촛불, "Q-28 · 체리 · 12살" 같은 번호·이름·나이 명판) ② 초록 **산책** 들판(정자 "추모관으로", 울타리, 나무) ③ **광장**: "위로받고 싶어요" 표지판, 바닥 원, "마음 선물 안내소" 부스, 촛불 선반 |

### 0.1.1 사용자 반응(스레드 댓글)에서 읽은 문제
- "분양 가능이 0개더라…ㅜ" → **희소성 설계가 애도 중인 사람을 줄 세운다.**
- "사물함 비우는 법 알려주세요" → 되돌리기/정리 동선 부재.
- "간식을 너무 많이 집어서 쟁반을 들고 다녀요, 삭제 어떻게…" → **인벤토리형 아이템**이 실수와 스트레스를 만든다.
- "산책에 두 마리 넣고 싶어요, 유료라도 살게요" → 다견·다묘 가정 수요가 분명하다.

### 0.1.2 구름다리 휴게소의 대응 (가져오기 / 더 잘하기 / 안 가져오기)

| 꼬리별 | 구름다리 휴게소 | 판단 |
|---|---|---|
| 사물함 번호·구역·검색·걸어가기 | **별 번호(1-07)·구역·이름/번호 검색·바로 가기** ✅ | 가져옴 |
| 분양제(빈 자리 0) | **희소성 없음**. 나선형 정원이 무한히 넓어짐. 마리 수 제한 없음 ✅ | 더 잘함 |
| 산책 + 아이의 1인칭 말풍선 | **같이 산책하기** ✅ (다리 끝까지 동행). 말풍선 대신 **서술형 캡션**("몽이가 잠깐 멈춰 풀냄새를 맡아요") | 가져오되 톤 바꿈 |
| 울애기 | **내 아이** 버튼 ✅ (여러 마리면 목록) | 가져옴 |
| 아바타 꾸미기 | 옷 색·머리 장식·이름표 ✅ | 가져옴 |
| 조약돌 | **조약돌 탑** ✅: 돌 하나에 한 줄, 탑이 실제로 쌓임. 인벤토리 없음 | 재해석 |
| 간식/선물 인벤토리 | 인벤토리 없음. 누르면 바로 별 앞에 놓임 ✅ | 더 잘함 |
| 위로받고 싶어요 광장 | **위로의 광장 게시판** ✅: 답글 없음, "토닥"만. 실시간 아바타는 V1 | 가져오되 안전하게 |
| 손(제스처) | 👋 인사 · 🙏 묵념 · 💗 하트 ✅ | 가져옴 |
| 접속 N명 | 로컬 단계에선 표시 안 함(가짜 숫자 금지). V1 presence 후 표시 | 보류 |
| 채팅 | 자유 채팅 없음(미성년·취약 사용자 보호). 이모지 반응만 (V1) | 안 가져옴 |
| 어두운 실내 톤 | 파스텔 야외. 밤 모드로 차분함은 제공 | 안 가져옴 |
| PWA 홈 화면 추가 | manifest·아이콘·안내 ✅ | 가져옴 |
| 줌 ± | ✅ | 가져옴 |

### 0.2 왜 지금인가 (근거)

- 농림축산식품부 「2025년 반려동물 양육현황 조사」(2026.02 발표, 국가승인통계): 반려동물 양육 가구 비율 **29.2%**.
- KB금융경영연구소 「2025 한국 반려동물 보고서」: 사별 경험 가구 중 **54.7%** 가 펫로스 경험, 그중 **83.2%** 가 심각한 상실감·우울감. 가장 흔한 증상은 "돌봄 부족에 대한 자책·후회"(71.5%, 복수응답). 충격은 **20·30대, 1인 가구**에서 더 큼.
- 수치 해석 주의: 농식품부와 KB 는 표본·산정 방식이 달라 가구 수를 직접 비교하면 안 된다. 펫로스 수치는 민간 보고서다.

## 1. 제품 정의

| 항목 | 내용 |
|---|---|
| 한 줄 | 먼저 떠난 반려동물을 위한, 알록달록한 구름 위의 추모 메타버스 |
| 핵심 약속 | "아이는 여기서 아프지 않고, 기다리지 않고, 잘 쉬고 있어요" |
| 핵심 행동 | 별 만들기 → 아이 곁에 가기 → 무언가 놓고 가기 → 다시 오기 |
| 톤 | 슬픔을 부정하지 않되 어둡지 않게. 파스텔·낮은 채도의 레인보우. 존댓말, 짧은 문장 |
| 안 하는 것 | 애도 중 결제 유도, 아이 목소리/인격 흉내 내는 AI, 추모 데이터 인질(언제든 내보내기) |

### 1.1 타깃

| 페르소나 | 상황 | 원하는 것 | 우리의 답 |
|---|---|---|---|
| **1인 가구 20·30대 보호자** | 아이를 보낸 직후, 주변에 말할 사람이 적음 | 유난이 아니라는 확인, 매일 들를 곳 | 별·펫 아바타·편지·힐링 라운지 |
| **가족 단위 보호자** | 가족 각자 애도 방식이 다름 | 함께 기억하는 장소, 아이들(자녀)도 쓸 수 있는 형태 | 공유 링크·가족 공동 관리(V1)·그림 같은 월드 |
| **장례식장·동물병원** | 장례 이후 케어가 비어 있음 | 보호자에게 건넬 "다음" | B2B 화이트라벨·QR 메달(V2) |

### 1.2 경험 원칙 (버전업의 기준)

1. **공간이 먼저**: 메뉴가 아니라 장소로 기억되게. 모든 기능은 월드 안의 사물(우체통, 나무, 문)에 붙인다.
2. **아이가 살아 움직인다**: 별 옆에서 아이 아바타가 거닐고, 보호자가 다가가면 반긴다. 과장하지 않는다(말하지 않는다).
3. **혼자가 아니다**: 다른 아이들의 별이 보이고, 남이 놓은 꽃이 보인다. V1에서 실시간 방문자까지.
4. **의식(ritual)이 있다**: 별 생성 세리머니, 보름밤 합동 등불, 기일 알림. 애도는 반복되는 의식에서 가벼워진다.
5. **취약한 순간에 팔지 않는다**: 생성 흐름·추모 카드에 결제 버튼 없음. 유료는 "더 꾸미고 싶을 때" 설정에서만.

## 2. 월드 설계 (현재 구현 ✅ / 다음 🔜)

```
                 [빛의 문]  ✨ ───── 구름 정거장 (x≈98, y≈31)
                    │
          무지개 구름다리 🌈 (7색 산책로, 난간 등)
                    │
 ┌──────────────────┴─────────────────────────┐
 │  섬 (반지름 25)                             │
 │   NW 힐링 라운지(건물)      NE 기억의 나무   │
 │          중앙 광장 · 순환로 · 벤치           │
 │   SW 하늘 우체통            SE 별빛 정원     │
 │                  S 입구                     │
 └────────────────────────────────────────────┘
   주변: 떠다니는 구름, 떠오르는 7색 등불, 꽃잎, 밤의 반딧불·별
```

| 존 | 역할 | 상호작용 | 상태 |
|---|---|---|---|
| **입구/광장** | 첫인상, 환영 간판, 벤치 | 둘러보기 | ✅ |
| **별빛 정원** | 아이들의 별(받침+빛 구슬+이름표), 아이 아바타가 주변을 거닒 | 살펴보기 → 추모 카드(꽃·간식·촛불·쓰다듬기, 편지, 공유, 아이 곁으로) | ✅ |
| **하늘 우체통** | 특정 아이 또는 모두에게 편지 | 편지 쓰기 | ✅ |
| **기억의 나무** | 익명의 위로 잎 달기(무작위 아이에게 전달) | 잎 달기 | ✅ |
| **힐링 라운지** | 보호자 쉼터: 오늘의 통계, 펫로스 안내, 위기상담 번호 | 들어가기 | ✅(모달) 🔜(실내 공간) |
| **구름다리** | 섬→하늘 산책로, 다리 안내 | 걷기 | ✅ |
| **빛의 문** | 다리 끝. 아이들만 지나는 문, 속으로 말하기 | 서기 | ✅ |
| **세리머니** | 새 별 생성 시 아이가 문에서 나와 다리를 건너 별에 도착 (약 11초, Esc 건너뛰기) | 자동 | ✅ |
| **낮·노을·밤** | 실제 시간 연동 + 수동 전환, 밤엔 반딧불·별 | 버튼 | ✅ |
| 합동 추모의 밤 | 매달 보름 20:00 KST, 모두의 등불이 동시에 올라감 | 이벤트 | 🔜 V1 |
| 계절 | 봄 벚꽃(현재 기본) → 여름 반딧불 강화 → 가을 낙엽 → 겨울 눈 | 자동 | 🔜 V1 |
| 내 섬 꾸미기 | 별 주변 조형물(집, 캣타워, 방석) 배치 | 편집 | 🔜 V2 |

### 2.1 펫 아바타
- 종: 강아지, 고양이, 토끼, 새, 햄스터·설치류, 그 밖의 아이. 색은 별 빛깔과 동일.
- 전부 원시 도형(구·캡슐·원뿔)으로 만든 로우폴리 → 외부 에셋·로딩 없음, 어떤 기기에서도 가볍다.
- 행동: 자기 별 주변 1.4~4m 거닐기 → 보호자가 6m 안에 오면 다가와서 1.4m 앞에 멈춤 → 2.2m 안이면 "반가움"(꼬리·고개·점프).
- 머리 위 작은 후광: "떠난 아이"라는 표식. 말풍선·음성 없음(원칙 2).

### 2.2 별(추모 유닛)
- 받침 + 색 링 + 떠 있는 빛 구슬 + 이름표 + (사진이 있으면) 둥근 액자 메달리온. 올린 수에 따라 꽃(최대 10), 향(최대 3, 연기 애니메이션), 촛불(최대 6), 간식(최대 5)이 실제로 받침 주변에 쌓인다. 쓰다듬기 수에 따라 빛이 커진다.
- 배치: 정원 중심의 황금각 나선 → 몇 백 개까지 겹침 없이 확장. 1,000개 이상이면 "정원 2구역"(섬 추가) 로 확장(V1).

## 3. 기능 목록

### 3.1 MVP (구현 완료)
- 입장 화면(방문자 이름), 입장 전 섬을 도는 시네마틱 카메라
- 3인칭 이동(WASD/방향키/조이스틱), 드래그 시점, 휠 줌, 섬·다리·정거장 지형 충돌
- 별 만들기: 이름·호칭·종·품종·생일·건넌 날·별 빛깔·사진(256px 로 자동 축소)·한마디
- 세리머니(구름다리 건너기) → 추모 카드 자동 오픈
- 추모 카드: 함께한 일수/건넌 지 일수 자동 계산, 올리기 3종(향·초·꽃), **사진 앨범**(여러 장 업로드·대표 사진·삭제·크게 보기, 최대 10장), 편지 목록, 공유, 아이 곁으로 이동, 별 내리기
- 월드 반영: 사진은 별 앞 둥근 액자 메달리온으로(여러 장이면 6초마다 바뀜), 향은 향로·향·피어오르는 연기로, 초·꽃은 받침 둘레에 실제로 쌓임
- 하늘 우체통(대상 선택), 기억의 나무(익명 위로), 힐링 라운지, 도움말, 다리/문 안내
- 별 목록(최근순, 헌화·편지 수) → 순간이동
- 낮/노을/밤, 반딧불, 별하늘, 꽃잎, 등불, 생성음(WebAudio, 외부 파일 없음)
- 공유 링크: 별 데이터를 URL 해시에 담아 **백엔드 없이** 가족에게 전달(열면 상대 기기에 별이 생김)
- 샘플 별 6개(삭제 불가 표시) — 빈 정원으로 시작하지 않게
- (꼬리별 분석 반영) 별 번호·구역·검색, 같이 산책하기, 내 아이 버튼, 아바타 꾸미기·이름표, 감정 표현 3종, 조약돌 탑, 위로의 광장 게시판(토닥), PWA 홈 화면 추가, 줌 버튼

### 3.2 V1 (계정·동기화·함께 있기) — 4~6주
| 기능 | 설명 |
|---|---|

## 4. 기술 아키텍처

### 4.1 현재 (MVP)
- **Vite + three.js(0.187)**, 프레임워크 없음. 빌드 결과 ≈ 160KB gzip. 외부 폰트·에셋·CDN 0개 → 어디서든 즉시 로드.
- 렌더링: 조명 3개(반구+태양+환경), 그림자 없음(가짜 그림자 원판), 꽃·꽃잎은 InstancedMesh → 저사양 폰에서도 동작.
- 저장: `localStorage` (`cloudbridge.v1`), 공유는 URL 해시 base64url.
- 배포: GitHub Pages 워크플로 포함, `public/CNAME` = bridge.metacint.com.

### 4.2 V1 목표 구조
```
브라우저(three.js SPA, 정적 호스팅)
   │  REST/Realtime (supabase-js)
   ▼
Supabase: Auth(카카오/구글) · Postgres(별/편지/헌화/가족) · Storage(사진/음성) · Realtime(presence, 등불 이벤트)
   │
   ├─ Edge Function: 알림(이메일/알림톡), 욕설·위기 문구 필터, 이미지 리사이즈
   └─ cron: 기일 알림, 보름 이벤트 스케줄
```
- `src/store.js` 가 유일한 저장 경계. 함수 시그니처(add/get/offer/addLetter…)를 유지한 채 구현만 Supabase 로 교체.
- Presence 는 위치(x,z,yaw)를 초당 5회 브로드캐스트, 같은 섬 50명 상한 → 넘으면 섬 인스턴스 분할("정원 2구역").

### 4.3 데이터 모델 (V1)
```
memorials(id, owner_user_id, name, species, breed, color, born, passed, epitaph, photo_url, created_at, visibility)
memorial_members(memorial_id, user_id, role: owner|family, nickname)
offerings(id, memorial_id, user_id?, type: flower|treat|candle|pat, created_at)
letters(id, memorial_id?, from_name, body, is_public, created_at, flagged)
events(id, kind: full_moon|anniversary, scheduled_at)
```

## 5. 수익 모델 (정액제 없음 · 애도 중엔 팔지 않는다)

월 구독은 두지 않는다. 보호자 입장에서 "아이를 계속 기억하려면 매달 내야 한다"는 구조 자체가 부담이고, 끊는 순간 죄책감을 만들기 때문이다. 대신 **기본은 영구 무료, 원할 때만 1회 결제** 로 간다.

| 구분 | 내용 | 가격 가설 |
|---|---|---|
| 무료(영구) | 별 무제한, 사진 앨범 10장, 향·초·꽃 무제한, 편지, 공유, 영구 보관 | 0 |
| 꾸미기 아이템(1회) | 특별 조형물(집·방석·캣타워), 별자리 연결, 배경음, 계절 한정 장식. 산 건 영구 | 1,000~4,900원 |
| 별 업그레이드(1회) | 사진 무제한·영상 3개·음성 보관함·액자 디자인 | 19,000원 |
| 후원(선택) | "다른 아이들에게 꽃 놓기" 후원. 금액 자유, 익명. 정원 전체에 꽃이 늘어남 | 자유 |
| 실물 연계(1회) | QR 메달·목걸이·액자(별 링크 인쇄). 제작 파트너 수수료 | 15,000~39,000원 |
| B2B(건당) | 장례식장·동물병원이 장례 1건당 입장권+메달 번들 구매. 월 고정비 없음 | 건당 5,000~9,000원 |

- 결제 동선은 **설정 → 별 꾸미기** 에서만. 생성·추모 카드·세리머니·분향 화면에 결제 UI 없음.
- 무료 사용자의 데이터를 유료 전환 지렛대로 쓰지 않는다(내보내기 항상 가능, 무료 기능을 나중에 유료로 돌리지 않는다).
- 운영비 가설: 정적 호스팅 0원 + Supabase 무료~25달러/월 수준. 1회 결제와 B2B 건당으로 충분히 덮인다.
