# 동시 접속 2,000명 설계 — 분향소(별의 방)와 집(섬)을 어떻게 나눌까

> 리도의 질문: "사람이 2천 명 정도 몰리면 분향소랑 집은 어떻게 하는 게 좋은데?"
> 그리고 "다른 사람들 보니 50개 단위로 채널을 분리했더라, 트래픽 때문인 것 같아."

## 1. 먼저 분리해서 생각할 것 두 가지

| 축 | 뜻 | 한계가 오는 곳 |
|---|---|---|
| **데이터 규모** | 별(추모 유닛)이 몇 개냐 | 렌더링(폰 GPU), 로딩 용량 |
| **동시 접속** | 한 장면에 사람이 몇 명 같이 있냐 | 실시간 네트워크(위치 브로드캐스트), 그리고 "붐빈다"는 체감 |

꼬리별이 50개 단위로 나눈 건 **둘 다**를 동시에 잡는 가장 단순한 방법이다. 공간 하나당 사물함 50개 → 거기 올 사람도 자연히 제한된다. 우리도 같은 결론인데, 두 축을 따로 조절할 수 있게 설계했다.

## 2. 현재 구현 (이 커밋 기준)

- **섬(구역) 하나에 별 50개** (`ISLAND_CAP = 50`). 51번째 별부터 새 "구역 섬"이 본섬 둘레 고리 위에 떠오르고, 구름 길(난간 등이 있는 산책로)로 본섬과 이어진다. 번호는 `3-27` 식. 구역 섬은 9개마다 한 고리씩 바깥으로 확장된다(이론상 무한).
- **거리 컬링**: 48m 밖 펫 아바타는 멈추고 숨김, 9m 밖 이름표 숨김, 45m 밖 헌화 장식 숨김. 2,000개 별 = 40개 섬을 한 장면에 둬도 화면에 그려지는 건 근처 섬 1~2개뿐이다. 헤드리스 소프트웨어 렌더러(GPU 없음) 기준 200개 별에서 에러 0. 실제 폰 GPU 수치는 배포 후 측정해야 한다.
- **별의 방(분향소)**: 별을 살펴보면 그 자리에서 카메라가 다가가고 디오라마 방이 펼쳐진다. 이때 반경 8m 안의 이웃 별과 아바타는 잠시 숨긴다. 즉 **분향은 항상 "내 아이와 둘만 있는" 뷰**다. 사람이 2,000명이어도 분향소는 붐비지 않는다.

## 3. 실시간(V1)에서의 채널 설계

"채널"은 같은 실시간 방에 묶여 서로 보이는 사람들의 단위다. 권장안:

```
채널 키 = 섬 번호 + 인스턴스 번호     예) island:3#2
인스턴스 정원 = 40명 (붐빔 체감 상한), 꽉 차면 #3 생성
본섬(광장·휴게소·우체통)만 예외: 정원 60명, 인스턴스 여러 개
```

- **왜 40명인가**: Supabase Realtime presence 는 채널당 수백 명도 받지만, 위치를 초당 5회 뿌리면 40명 × 5회 × 40명 수신 = 초당 8,000메시지/채널이 상한선 근처다. 그리고 화면에 아바타 40명이면 이미 "광장이 가득 찼다"는 느낌이 난다. 체감과 기술 한계가 같은 자리에서 만난다.
- **2,000명 동시 접속 시**: 본섬 인스턴스 ~10개 + 구역 섬 인스턴스 ~40개 = 채널 50개 내외. Supabase Pro(월 25달러) 동시 연결 500 기본 + 추가 과금, 또는 자체 WebSocket 서버(Node + uWebSockets, 소형 VM 1대로 2,000 연결은 여유) 중 택일. 초기엔 Supabase, 월 접속자가 꾸준히 2,000을 넘으면 자체 서버로 옮기는 걸 권한다.
- **같은 별을 가족이 같이 보고 싶을 때**: 인스턴스가 달라도 "초대 링크"로 같은 인스턴스에 합류시킨다(URL에 `#i=3-2`).
- **분향소는 채널이 아니다**: 별의 방은 로컬 뷰라 네트워크 부하 0. 향·초·꽃 카운트만 DB 에 쓰고, 같은 별을 보는 사람에겐 "방금 누가 향을 올렸어요" 토스트만 브로드캐스트한다. 2,000명이 동시에 분향해도 서버 입장에선 초당 2,000건의 작은 INSERT 뿐이다(Postgres 가 하품할 양).

## 4. "집"(섬)을 더 나눠야 할까

- 지금: 섬 = 50개 별. 섬은 **데이터 단위**이지 트래픽 단위가 아니다. 트래픽은 위의 인스턴스가 받는다.
- 50이 맞는 이유: 황금각 나선에서 50개면 반지름 14m 안에 2.4m 간격으로 들어가고, 한 화면(줌 아웃)에 섬 하나가 통째로 보인다. 100개면 이름표가 겹치기 시작했다(실험함).
- 대안으로 검토했다가 버린 것: ① 종별 섬(강아지 섬, 고양이 섬) → 가족이 둘 다 키우면 갈라진다. ② 날짜별 섬 → 오래된 별이 변두리로 밀려나 "잊힌" 느낌. 번호순 섬이 가장 중립적이다.
