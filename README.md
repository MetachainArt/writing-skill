# 글쓰기 12단계 워크플로우 스킬

Claude Code용 글쓰기 12단계 워크플로우 스킬입니다.

## 설치

`commands/` 폴더의 모든 `.md` 파일을 아래 경로에 복사하세요:

```
C:\Users\[사용자명]\.claude\commands\
```

## 스킬 목록

| 명령어 | 설명 |
|--------|------|
| `/writing` | 전체 워크플로우 오케스트레이터 |
| `/writing-1-think` | 1단계: 생각/구상/관찰하기 |
| `/writing-2-topic` | 2단계: 주제 정하기 |
| `/writing-3-research` | 3단계: 자료 준비하기 |
| `/writing-4-organize` | 4단계: 정리하기 |
| `/writing-5-outline` | 5단계: 목차 짜기 |
| `/writing-6-style` | 6단계: 문체 모방하기 |
| `/writing-7-draft` | 7단계: 초안 쓰기 |
| `/writing-8-self-edit` | 8단계: 직접 다듬기 |
| `/writing-9-master` | 9단계: 거장에게 첨삭 받기 |
| `/writing-10-polish` | 10단계: 퇴고 |
| `/writing-11-finalize` | 11단계: 완성 |
| `/writing-12-publish` | 12단계: 발행 |

## 사용법

Claude Code에서 아래처럼 말하면 자동으로 스킬이 활성화됩니다:

- "글쓰자"
- "에세이 써줘"
- "글감이 있어"
- "/writing"
